Using SFML to make a 3D world

**Features**
-3D camera, fps style camera, can be controlled using keyboard and mouse to look around

-Cube class which places 8 vertices and connects them to form a cube, takes position and side length to construct

-Circle class, takes radius and resolution (resolution = number of vertices placed to form the circle)

-Sphere class, places vertices and joins them, takes radius and resolution (resolution = number of latitude or longitudes generated)

-Screen recording using ffmpeg
